Pastry Mentoring

A website helping beginners learn pastry making by providing tested recipies.

1. Site Name

Site Name: Pastry Mentorin

Reason for Choosing the Name: The name tells users exactly what they get to learn from the website.

2. Site Purpose

The purpose of the website is to teach beginners how to make various pastries using ingredients accessible to them.

  • Beginner-friendly recipies
  • Introduction to pastry tools
  • Ingredient infomation
  • Where to access ingredients
  • Tips for pastry making

3. Scenarios

Below are questions typical visitors may ask, which the site will answer:

  • “How to make pastries?”
  • “What tools to use?”
  • “Where to find tools and ingredients?”

4. Color Schema

The following colors will be used throughout the website:

#2E7D32 (Green) – Used for headings, accents, buttons.

#F5F2E8 (Beige) – Used for background and content sections.

5. Typography

The website will use two fonts:

  • Montserrat – used for headings
  • Open Sans – used for body text
